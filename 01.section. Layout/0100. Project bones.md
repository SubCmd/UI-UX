## 0-1. 프로젝트 폴더 구조
 
파일이 늘어나면 정리 안 된 폴더는 금방 지옥이 됩니다. 처음부터 규칙을 정합니다.
 
### ❌ 나쁜 예 — 전부 한 폴더에 뒤섞기
```
내 프로젝트/
├── index.html
├── style.css
├── 또다른스타일.css
├── 사진1.jpg
├── 로고.png
├── script.js
├── index 복사본.html
└── 백업_최종_진짜최종.css
```
> 파일이 10개만 넘어가도 뭐가 뭔지 못 찾습니다. "복사본", "최종" 같은 이름은 미래의 나를 괴롭힙니다.
 
### ✅ 좋은 예 — 종류별로 폴더 분리
```
my-site/
├── index.html          ← 페이지 (HTML)
├── css/
│   └── style.css       ← 스타일
├── js/
│   └── main.js         ← 동작 (나중에)
└── assets/
    └── images/
        ├── logo.png
        └── hero.jpg     ← 이미지·폰트 등
```
> **규칙:** HTML은 맨 위, CSS는 `css/`, JS는 `js/`, 이미지는 `assets/images/`.
> 이 한 가지 구조만 평생 써도 됩니다. 프로젝트가 커져도 무너지지 않습니다.
