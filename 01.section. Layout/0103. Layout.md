# Phase 3 — 레이아웃 (Flexbox & Grid)
 
> **이번 시간의 목표**
> 요소를 '원하는 위치에 정확히' 배치합니다.
> 핵심 도구는 딱 둘 — **Flexbox**(한 줄 정렬)와 **Grid**(격자 배치)
> 이 둘이면 "가운데 정렬이 안 돼요", "카드가 안 나란해요" 같은 초보의 고통이 사라집니다.
 
---
 
## 3-1. 왜 이제 float은 안 쓰나 (짧게)

예전에 `float`으로 요소를 나란히 놓았음. 하지만 float은 원래 '글 옆에 이미지를 흘려보내는' 용도였음.
레이아웃에 억지로 쓰면 높이가 무너지고(부모가 찌그러짐), 이를 고치는 `clearfix` 같은 해킹이 필요함.

```css
/* ❌ 옛날 방식 — 배우지 않아도 됨. */
.box {
    float: left;
    width: 33%;     /* 정렬·간격 계산이 지옥 */
}
```
> 결론:
> float은 이제 레이아웃에 사용하지 않음.
> 옛날 코드에서 보면 "아, 구식이구나" 정도만 알면 충분함.

---

## 3-2. "가운데 정렬이 안 돼요" - 고통의 끝

초보가 가장 많이 검색하는 문제임.
옛날엔 이걸 맞추려고 온갖 해킹을 썼음.

### ❌ 나쁜 예 — 옛날 중앙 정렬 해킹
```css
/* 가로만 겨우 되던 방식 (세로 중앙은 별도) */
.box {
    width: 200px;
    margin: 0 auto;
}

/* 세로 중앙 맞추려던 마법 주문 (외우기도 힘듦) */
.item {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```
> 상황마다 방법이 달라 매번 검색해야 하고, 응용이 안 됨.

### ✅ 좋은 예 — Flexbox 3줄이면 완벽한 중앙
```css
.container {
    display: flex;
    justify-content: center;    /* 가로 중앙 */
    align-items: center;        /* 세로 중앙 */
    height: 300px;
}
```
> 가로든 세로든, 요소가 하나든 여럿이든 **이 3줄**이면 끝.
> 이 순간 Flexbox를 배우는 이유!

---

## 3-3. Flexbox 기본 - 한 줄 정렬의 끝판왕

> **용어 풀이 — Flexbox:** 요소들을 한 줄(가로 또는 세로)로 세워두고 "정렬해, 간격 둬"라고 명령하는 도구. **1차원**(한 방향)을 다룹니다.

부모에 `display: flex`를 주면, 그 안의 자식들이 Flex 규칙을 따름.

```css
.parent {
    display: flex;              /* 이 순간 자식들이 가로로 나란히 */
    flex-direction: row;        /* row=가로(기본), column=세로 */
    justify-content: center;    /* '늘어선 방향'으로 정렬 */
    align-items: center;        /* '가로지르는 방향'으로 정렬 */
    gap: 16px;                  /* 자식들 사이 간격 (margin 안 써도 됨!) */
}
```

### `justify-content` 값별 배치 (아이템 3개가 가로로)
```
flex-start     │[A][B][C]                │
center         │         [A][B][C]       │
flex-end       │                [A][B][C]│
space-between  │[A]        [B]        [C]│   ← 양끝에 딱 붙고 사이 균등
space-around   │   [A]    [B]    [C]     │   ← 각 아이템 좌우에 여백
space-evenly   │    [A]    [B]    [C]    │   ← 모든 간격이 똑같음
```


### 실전: 내비게이션 바

#### ❌ 나쁜 예 — inline-block으로 안간힘
```css
.menu li {
  display: inline-block;
  margin-right: 20px;   /* 마지막 항목에도 여백이 남아 삐침 */
}
/* 로고를 왼쪽, 메뉴를 오른쪽 끝으로 밀기 → 매우 어려움
   세로 중앙 정렬 → 또 별도 해킹 */
```

#### ✅ 좋은 예 — Flexbox
```css
.navbar {
  display: flex;
  justify-content: space-between;  /* 로고는 왼쪽 끝, 메뉴는 오른쪽 끝 */
  align-items: center;             /* 로고·메뉴 세로 중앙 자동 정렬 */
}
.menu {
  display: flex;
  gap: 24px;   /* 메뉴 항목 간격, margin 계산 불필요 */
}
```
```html
<nav class="navbar">
  <h1>내 사이트</h1>
  <ul class="menu">
    <li><a href="#">홈</a></li>
    <li><a href="#">소개</a></li>
    <li><a href="#">연락처</a></li>
  </ul>
</nav>
```

> **핵심:**
> 항목 사이 간격은 `margin`이 아니라 **`gap`**을 쓰기!
> 마지막 항목 삐침 문제가 없고 코드도 깔끔함

## 3-4. Grid 기본 — 격자·표 배치의 정석
 
> **용어 풀이 — Grid:** 모눈종이처럼 행·열 격자를 만들어 배치하는 도구. **2차원**(가로+세로 동시)을 다룹니다.
 
```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 균등한 3열 */
  gap: 24px;                              /* 칸 사이 간격 (가로·세로 모두) */
}
```
> **용어 풀이 — `fr`(fraction, 비율 단위):** `1fr` = "남은 공간 1칸".
> `repeat(3, 1fr)`는 "남은 공간을 똑같이 3칸으로 나눠라"라는 뜻. `repeat(3, 1fr)`은 `1fr 1fr 1fr`을 짧게 쓴 것.
 
### 배치 결과
```
grid-template-columns: repeat(3, 1fr)  +  gap
 
┌──────┐ ┌──────┐ ┌──────┐
│  A   │ │  B   │ │  C   │
└──────┘ └──────┘ └──────┘
┌──────┐ ┌──────┐ ┌──────┐
│  D   │ │  E   │ │  F   │   ← 6개를 넣으면 자동으로 2행 배치
└──────┘ └──────┘ └──────┘
```
 
### 실전: 카드 갤러리
#### ❌ 나쁜 예 — float/inline-block으로 격자 흉내
```css
.card {
  float: left;
  width: 30%;
  margin: 1.5%;   /* 30% + 여백 계산이 딱 안 떨어져 줄바꿈이 깨짐 */
}
/* 카드 개수가 3의 배수가 아니면 마지막 줄이 이상하게 정렬됨 */
```
 
#### ✅ 좋은 예 — Grid
```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}
.card {
  /* width 지정 불필요! 열 개수와 gap이 알아서 계산 */
  padding: 24px;
  border: 1px solid #e5e5e5;
  border-radius: 8px;
}
```

> Grid는 각 카드의 너비를 직접 계산할 필요가 없음
> "3열로 나눠줘"만 말하면 나머지는 브라우저가 정확히 계산합니다.
 
---
 
## 3-5. 언제 Flexbox, 언제 Grid?
 
한 문장으로 구분됨.
 
| | Flexbox | Grid |
|---|---------|------|
| 다루는 방향 | **1차원** (한 줄: 가로 *또는* 세로) | **2차원** (행 + 열 동시) |
| 잘 맞는 곳 | 메뉴바, 버튼 묶음, 정렬, 중앙 맞추기 | 카드 갤러리, 대시보드, 페이지 전체 뼈대 |
| 판단 기준 | "한 줄로 늘어놓나?" | "표처럼 칸을 나누나?" |
 
> 헷갈리면 이렇게 생각하기
> **"일렬로 세운다"면 Flex, "바둑판처럼 칸을 나눈다"면 Grid.**
