## 3-1. 왜 이제 float은 안 쓰나 (짧게)

예전에 `float`으로 요소를 나란히 놓았음. 하지만 float은 원래 '글 옆에 이미지를 흘려보내는' 용도였음.
레이아웃에 억지로 쓰면 높이가 무너지고(부모가 찌그러짐), 이를 고치는 `clearfix` 같은 해킹이 필요함.

```css
/* ❌ 옛날 방식 — 배우지 않아도 됨. */
.box {
    float: left;
    width: 33%;     /* 정렬·간격 계산이 지옥 */
}
```
> 결론:
> float은 이제 레이아웃에 사용하지 않음.
> 옛날 코드에서 보면 "아, 구식이구나" 정도만 알면 충분함.

---

## 3-2. "가운데 정렬이 안 돼요" - 고통의 끝

초보가 가장 많이 검색하는 문제임.
옛날엔 이걸 맞추려고 온갖 해킹을 썼음.

### ❌ 나쁜 예 — 옛날 중앙 정렬 해킹
```css
/* 가로만 겨우 되던 방식 (세로 중앙은 별도) */
.box {
    width: 200px;
    margin: 0 auto;
}

/* 세로 중앙 맞추려던 마법 주문 (외우기도 힘듦) */
.item {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```
> 상황마다 방법이 달라 매번 검색해야 하고, 응용이 안 됨.

### ✅ 좋은 예 — Flexbox 3줄이면 완벽한 중앙
```css
.container {
    display: flex;
    justify-content: center;    /* 가로 중앙 */
    align-items: center;        /* 세로 중앙 */
    height: 300px;
}
```
> 가로든 세로든, 요소가 하나든 여럿이든 **이 3줄**이면 끝.
> 이 순간 Flexbox를 배우는 이유!
